# ADR 0002 · Hosting y dominio

Fecha: 2026-10-11. Estado: Hobby y dominio pendiente confirmados por el titular.

Vercel Hobby para demostración personal sin actividad comercial. Antes de vender, confirmar un plan comercial; no contratarlo automáticamente. No existe despliegue creado en esta fase.

El dominio definitivo queda pendiente. Un dominio estable de proyecto Vercel podrá usarse para pruebas después de conectar la cuenta. No usar una URL efímera de preview como enlace de tarjetas definitivas. Las tarjetas de prueba deben identificarse como tales. Elegir otro dominio después puede romper QR impresos; no hay promesa de migración transparente sin conservar el dominio anterior y redirecciones.

Previews con información ficticia y Vercel Authentication cuando se configure. Su disponibilidad no significa protección activa de la cuenta. El administrador tendrá además autorización de aplicación; Deployment Protection no la sustituye.

Gate interno: contar funciones reales del artefacto del adaptador, máximo 10. En ausencia del artefacto, fallar cerrado. El build local solo demuestra 3 rutas Next dinámicas. [Verificación de plataforma](../PLATAFORMAS.md).
